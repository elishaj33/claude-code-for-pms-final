Added after reviewing gaps in the brief. Items marked option are reasoned, not tested.
  • Out-of-area misses don't count against recent acceptance (shown above). The code never recorded why those pings were never taken before 4.2; question for Wen.
  • Easing back toward neutral is a safety net, not the fix. In the replay, easing alone did not lift the four. This answers the 2019 note in history.py.
  • Monitoring: record how long each responder takes to answer, log score changes, and alert the handler card when a responder has had no pings for 7 days (the "Gone quiet" banner). Today none of this is recorded.
  • Option: grace window. Keep a ping answerable until someone else takes it, for the "gone before I could answer" tickets (about a third). Needs Wen.
  • Option: daily loss cap. No responder loses more than a set number of points in a day, so one bad evening can't send anyone to the floor.
  • Option: delivery check. The code never checks a push arrived; "phone never goes off" is two thirds of the tickets and is still not explained.

Rollout

  • Who runs the one-off reset, and when. Start with the four quiet responders.
  • Confirm scores survive a restart (they're held in memory only), or the fresh start could be wiped.
  • A way to switch the change off.
  • Baselines cut at 12 Aug, not Mondays; check whether callout counting changed that day.
